# 💜 Zato — Assistente Financeiro Pessoal

> Controle seu dinheiro. Simples assim.

O **Zato** é um assistente financeiro pessoal desenvolvido como projeto acadêmico na FIAP, com foco em ajudar o usuário a visualizar e controlar suas finanças de forma clara e intuitiva.

---

## 🖥️ Tela desenvolvida

![Dashboard Zato](https://raw.githubusercontent.com/enzocarezzato/zato-fintech/main/preview.png)

Dashboard principal com visão geral do saldo, receitas, gastos, contas conectadas, gráfico por categoria e histórico de transações.

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Tailwind CSS (via CDN)
- Google Fonts (Inter)

---

## ▶️ Como rodar o projeto

1. Clone ou baixe o repositório
2. Abra o arquivo `index.html` diretamente no navegador
3. Nenhuma instalação necessária

```bash
git clone https://github.com/enzocarezzato/zato-fintech.git
```

---

## 📱 Responsividade

O projeto foi desenvolvido com responsividade para dispositivos mobile, incluindo menu lateral adaptável e ocultação de colunas secundárias em telas menores.
